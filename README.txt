Files:

Testing:
1. Run the program in VS Code.
2. Choose 1 for Crime Data or 2 for Electric Vehicle Data.
3. Enter the name of the tab-separated .txt data file.
4. Enter a small number such as 50 for the first test.
5. After testing, run again and enter 0 to load the complete dataset.

Primary keys:
Crime Data = DR_NO
Electric Vehicle Data = VIN(1-10)

The two programs use the first field of each tuple as the primary key.
